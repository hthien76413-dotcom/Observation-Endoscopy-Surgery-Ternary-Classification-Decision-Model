# 儿童消化道异物「观察 / 内镜 / 手术」三分类决策模型

基于单中心 10 年（2016-07—2026-06）住院数据，建立并时间验证儿童消化道异物的
三分类治疗决策模型，并规划 SCI 论文产出。

## 队列

| | |
|---|---|
| 住院次数 / 唯一患儿 | 1238 / 1228 |
| 年龄 | 中位 3.2 岁（IQR 1.8–5.7） |
| 观察 / 内镜 / 手术 | 583 (47.1%) / 520 (42.0%) / 135 (10.9%) |
| 穿孔 | 78 (6.3%)，其中 44 例（56%）由磁性异物导致 |

## 预试验效能（5 折交叉验证）

| 模型 | 观察 AUC | 内镜 AUC | 手术 AUC | 宏平均 AUC |
|---|---|---|---|---|
| 多分类 Logistic | 0.719 | 0.728 | 0.908 | 0.785 |
| 随机森林 | 0.726 | 0.739 | 0.923 | 0.796 |

时间外部验证（2016–2023 → 2024–2026）：手术 AUC **0.945**，宏平均 AUC 0.773。

## 数据说明

原始数据 `10年消化道异物原始数据.xlsx` 含 20 个工作表的 EMR 抽取。
三个必须注意的特性详见 `docs/SCI论文写作方案.md` §一：

1. 内镜取异物记录在**手术/手麻系统**而非内镜报告表（该表仅 18 条）

## Fig 5 校准曲线与 DCA

```bash
python3 scripts/definitive_analysis.py     # 先跑，产出 outputs/predictions.csv
python3 scripts/build_figure5.py
```

上排逐类校准（交叉验证实线、时间验证虚线），下排逐类净获益。与 Fig 4 同规，
只读 `predictions.csv` 的 `cv` 与 `temporal`——**校准尤其不能画表观概率**：
惩罚 logistic 回归在自己的训练数据上几乎必然接近完美校准，画出来是一条贴着
对角线的直线，什么也没说明。

**这张图的要点是两条线的分离。** 判别力经受住时间验证（宏平均 0.799 → 0.779），
校准没有：

| | 观察 | 内镜 | 手术 |
|---|---|---|---|
| 交叉验证 斜率/截距 | 0.95 / −0.00 | 0.98 / −0.01 | 1.13 / +0.04 |
| 时间验证 斜率/截距 | 0.73 / **+0.43** | 0.87 / **−0.28** | 1.34 / **−0.55** |
| 构成比变化 | 47.1% → 55.9% | 42.0% → 36.3% | 10.9% → 7.7% |

截距漂移方向与构成比变化一致——截距正是承接患病率的那一项。结论是模型若要用于
后续年份，须先重估截距。只报 AUC 0.779 会让读者以为时间验证通过即可直接部署。

两处实现细节：

- **分箱数随样本量伸缩**（`n // 120`，限 4–10 箱）。时间验证 n=413、手术仅 32 例，
  硬切 10 箱会有半数箱子实际比例为 0，画出来是锯齿而不是校准。
- **DCA 阴影标出模型优于两条参照线的区间**（观察 0.15–0.71、内镜 0.07–0.79、
  手术 0.02–0.78），由脚本实算而非写死。低于该区间时 treat-all 更优，是阈值低于
  患病率时的常态，图注一并写明——只报优势区间会盖掉图上看得见的那段劣势区。

## 最小样本量核算

```bash
python3 scripts/sample_size.py
```

**结论是不够，而且必须照实写进正文。** 这是事后核算——队列为十年全部住院，
样本量不是设计出来的，所以回答的是「以现有事件数，32 个预测因子是否站得住」。

多分类没有单一公式，按 Pate/Riley 的做法拆成三组成对比较，各套二分类三准则，
取最严的一组倒推全队列所需例数。**R² 取交叉验证值而非表观值**——拿被高估的
效能去算样本量，等于为偏小的样本自我背书。

| 成对比较 | 折合全队列需 | 卡在哪条准则 |
|---|---|---|
| 观察 vs 内镜 | **2095** | 准则 1 收缩 S≥0.9 |
| 观察 vs 手术 | 1417 | 准则 2 R² 差 ≤0.05 |
| 内镜 vs 手术 | 1471 | 准则 2 |

实际 1238 例，三组都不满足。**所需例数随结局越难预测而上升**，观察／内镜正是最难
分开的那一对——这与本文核心论点同向，故写在 Methods 正文而非局限性里。

## 补充图 S1 插补诊断

```bash
python3 scripts/build_figure_s1.py [--imputations 20]
```

**读法与一般插补诊断相反。** 通常「插补值分布与观测值一致」被当作好现象；本队列
缺失携带治疗信息（内镜组 85% 没有 CRP），若两者严丝合缝，反而说明插补模型没用上
结局与协变量，只是把观测分布复制了一遍。要看的是：插补值落在临床可能范围内，
且偏移方向讲得通。

**这张图查出了一个真问题。** `IterativeImputer(sample_posterior=True)` 从无界正态
后验抽样，产生过负体重、负白细胞、−13% 与 109% 的中性粒细胞比例（11220 个值里
20 个）。已在 `observed_bounds()` 按观测范围夹边界修正；交叉验证里的边界只取自
训练折，避免跨折泄漏。修正后全部效能小幅上升——夹掉的本来就是噪声。

## 补充图 S2 学习曲线

```bash
python3 scripts/learning_curve.py [--repeats 10]
python3 scripts/learning_curve.py --replot   # 只改图内样式时用，跳过几分钟的插补模拟
```

**这张图要回答的不是「模型好不好」，是「观察/内镜分不开这件事，有没有另一种
解释」。** 本文核心论点是手术 AUC 0.91–0.96、观察/内镜仅 0.68–0.74 反映的是临床
决策本身的性质，不是模型缺陷。但 `sample_size.py` 显示这对比较按 Riley 标准需要
2095 例（实际 1238），单看这一条，低判别力完全可能只是「样本不够」。

学习曲线直接检验这一点：固定测试集（n=248，全程不参与任何训练）+ 训练池分层
子抽样（n=99→990，每个比例重复 10 次），看观察/内镜的 AUC 是持续爬升还是早早
走平。结果：**尾段斜率仅为头段的 0.10–0.12**（手术类作对照为 0.17，走平更早，
符合预期——它是最容易分开的类别）。方向上不支持「只是样本不够」。

**但这不是决定性证据，两处要点必须交代**：

- **不做超出观测范围的外推。** 曲线只到 n=990（当前训练池上限），走平也可能只是
  「当前规模内爬得慢」，不等于「给再多同类数据也不会涨」。
- **必须与 Riley 样本量核算并置陈述，不可用这条曲线掩盖那条核算。** 两者是同一
  个问题的两个视角：一个算「够不够」，一个测「涨没涨」，结论方向一致时互相佐证，
  不能只引其一。

**一处方法学简化，已在脚本文档字符串里交代**：每个「比例 × 重复」只做一次插补
抽样，不像主分析那样做 m 份 MI 合并——省下 m 倍算力，代价是单点比主分析的效能
估计更燥；重复本身在聚合层面部分补偿了这一点，但这条曲线的目的是看趋势方向，
不是给出另一个可报告的 AUC，不应与 Fig 4/5 同等严格看待。
