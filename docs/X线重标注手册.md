# X 线重标注手册

配套文件：`annotation/X线重标注表单.xlsx`

---

## 为什么做这件事

原放射科报告的定位文本无法用于建模。1073 例有 X 线报告，但结论多为
「消化道不透 X 光异物」「与前片比较异物位置移动」，**557 例未定位到具体消化道节段**。

后果：影像变量块对模型毫无贡献。剔除决策后拍摄的片子后，加入影像反而使宏平均 AUC
下降 0.003（0.782 → 0.779）——当前这些基于报告文本的定位标记只是噪声。

而**异物在食管／胃 还是 幽门以远，本该是「内镜 vs 观察」决策的第一生理依据**。
现在这个信息几乎没进模型，是全篇效能最大的缺口。预期重标注完成后，
观察／内镜的 AUC 可从 0.73 提升到 0.85 以上。

## 工作量

| 项目 | 数量 | 说明 |
|---|---|---|
| 总行数 | 1073 | 每行 = 一次住院的首次 X 线 |
| 术前片 | 488 | 拍摄早于手术开始，可直接用于建模 |
| 无手术 | 497 | 本次住院无手术，全部可用 |
| **可直接用于建模** | **985** | 上述两类之和 |
| 同日-时序不明 | 38 | 需在 PACS 核对拍摄时刻是否早于手术 |
| 决策后片 | 50 | 首次片已晚于手术开始；仍请标注，但建模时剔除 |
| 双人阅片 | 200 | 两位阅片者独立完成，用于 Cohen's Kappa |

预计约 9 小时（每例约 30 秒）。

> **「片子时相」这一列是怎么来的**：用手麻系统的「手术开始时间」（精确到分钟）
> 与 X 线检查时间比较。`住院病历手术记录` 的时间字段 100% 为 00:00、只有日期，
> 不能用于时序判定，仅在无手麻记录时降级为同日判定——这就是「同日-时序不明」
> 这 38 例的来源，需要人工查 PACS 确认。

## 填写规则

1. **只填黄色与浅绿表头的列。** 灰蓝表头是参考信息，请勿修改。
2. **黄色 = 必填**，浅绿 = 选填但有分析价值，能填尽量填。
3. 绝大多数列是下拉选择，不要手输。
4. **先看 PACS 原片形成自己的判断，再决定是否翻阅「原始报告」工作表。**
   原报告刻意与标注表分开放，就是为了避免被原描述带偏。
5. 「异物可见 = 否」时：部位填「无异物」，数目填「不能确定」，最大径填 0，
   成串成团填「不适用」。
6. **双人阅片行（标记为「是」的 200 行）由两人各填一份独立文件**，
   切勿互相参照，最后再合并算 Kappa。
7. **拿不准就填「不确定」／「不能确定」，并在备注写一句。不要猜。**
   刻意的「不确定」比勉强的猜测对模型更有价值。

## 字段定义

### 异物可见（必填）

首次片上是否见明确的不透 X 线异物。

**阴性同样是信息**——透光性异物（塑料、木质、部分鱼骨、多数食物团块）本就拍不到，
「异物可见 = 否」而临床仍按异物处理，这本身是模型要学的模式。

### 部位（必填）—— 本次重标注的核心

以**横膈、幽门、回盲部**为界。

| 取值 | 界定 |
|---|---|
| 食管上段 | 胸廓入口以上（环咽肌至胸廓入口） |
| 食管中段 | 胸廓入口至气管隆凸 |
| 食管下段 | 气管隆凸至贲门 |
| 胃 | 贲门至幽门 |
| 十二指肠 | 幽门至屈氏韧带 |
| 小肠 | 屈氏韧带至回盲瓣 |
| 结肠 | 回盲瓣至乙状结肠 |
| 直肠 | 乙状结肠以下 |
| 多处 | 多枚异物分布于不同节段 |
| 不能确定 | 见到异物但无法归入上述任一节段 |
| 无异物 | 异物可见 = 否 |

> **胃与幽门以远的区分最关键**——它直接决定内镜可及性，是「内镜 vs 观察」
> 决策的第一依据。食管分段拿不准时可填「不能确定」，但**胃 / 幽门以远
> 这一层请尽量给出判断**。

### 数目（必填）

按可见枚数分档：`1` / `2` / `3-5` / `≥6` / `不能确定`。

**成串吸附的磁珠按实际枚数计，不按串计。** 能准确计数时在「数目_精确」列填整数。

### 最大径_mm（必填）

最大一枚异物的最大径，毫米，整数。

**请用 PACS 测量工具实测，不要目测估计。** 指南阈值依赖这一项：
直径 >25 mm 或长度 >60 mm 难以通过幽门。

### 成串成团（必填）

两枚及以上异物相互吸附、聚集成串或成团。

**磁性异物的关键征象**，与肠壁夹持穿孔直接相关——本队列 78 例穿孔中 44 例
由磁性异物导致。单枚异物填「不适用」。

### 形态（选填）

最大一枚的形态：`圆盘状` / `球形` / `条状` / `不规则` / `其他` / `不能确定`。

### 双环征（选填）

圆盘状异物边缘的双环／晕环（halo）影，正位可见；侧位可见台阶征（step-off）。

**纽扣电池与硬币的鉴别要点。** 非圆盘状异物填「不适用」。

### 影像判断类型（选填）

`硬币样` / `纽扣电池样` / `磁性球形` / `尖锐金属` / `其他金属` / `非金属但可见` / `不能判断`

**仅凭影像判断，刻意不参考病史。** 与病史所述类型的不一致本身是有价值的数据
（家长常把纽扣电池说成硬币），请如实填写，不要向病史靠拢。

### 膈下游离气体 / 肠梗阻征象（选填）

- 膈下游离气体：立位胸腹片膈下新月形透亮影。卧位片无法评估时填「否」并在备注注明。
- 肠梗阻征象：肠管扩张伴气液平面。

## 完成之后

单人阅片：

```bash
python3 scripts/ingest_annotation.py annotation/X线重标注表单.xlsx
```

双人阅片（同时计算 Kappa）：

```bash
python3 scripts/ingest_annotation.py 阅片者A.xlsx 阅片者B.xlsx
```

输出 `outputs/xray_annotation.csv`，由 `build_cohort.py` 读入，取代原先基于
报告文本的正则定位；双人模式另出 `outputs/kappa_report.txt`。

**Kappa 报告是投稿必需材料**，审稿人会问自由文本／影像判读的可靠性。
一般 κ>0.80 为优秀，0.61–0.80 为良好。若某字段 κ<0.60，需要两位阅片者
重新讨论该字段的判读标准后返工。

## 质控要点

- **盲法**：工作清单**刻意不含治疗方式与结局**，避免阅片者因知道「这例做了手术」
  而倾向于读出更重的征象。请勿在标注期间查阅这些患儿的治疗经过。
- **先校准**：正式开始前，两位阅片者先共同标注 20 例并逐项对照，
  统一判读口径后再各自独立进行。
- **分批核对**：每完成 200 例，在「进度」工作表检查「定位到具体节段」的数量。
  若显著低于预期（原报告已能定位 516 例），说明判读偏保守，需复盘。
